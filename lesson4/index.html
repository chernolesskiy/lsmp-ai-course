When digits move

Move every test digit one pixel to the right and the network gets most of them wrong, though a person reads them just as easily. Don't change the network: change what it learns from, so a fresh network gets 85% on both the normal and the moved digits.

Check your understanding

Nearest neighbour scores 30 out of 30 on pictures from its own training set. Why does that prove nothing?

  1. 30 pictures are too few to count as a test
  2. Each of those pictures is in its memory, so the closest picture is the picture itself
  3. The training pictures are neater than the test pictures
  4. Nearest neighbour is always right, so every score is 100%

The distance from a picture to itself is 0, so it just looks the answer up. Only pictures it has never seen show whether it really works.

Remembering one real picture of each digit got about 68%. Remembering the average picture of each digit got about 92%. Why?

  1. Average pictures have more ink, so the distances are bigger
  2. The averages are taken from the test set
  3. An average is close to most pictures of its digit, while one real picture may be unusual
  4. Nearest neighbour only works with numbers that are not whole

One real 7 might be tilted or crossed. The average 7 sits in the middle of all the 7s, so new 7s tend to be closest to it.

A neuron painted with the whole shape of an 8 gets only about 79% of the 8s and 3s right. Which painting does better?

  1. Painting a bigger 8, so it covers more squares
  2. Painting every square with +, so it adds up all the ink
  3. Painting + in the middle of the picture, where both digits have the most ink
  4. Painting + only where 8s have ink and 3s don't, and − where only 3s have ink

Squares both digits use add the same amount to both, so they can't tell them apart. Only the differences matter.

Changing 4 squares can fool a network that was 99.9% sure, while a person still reads the same digit. What does that show?

  1. The network adds up weighted squares and has no idea of the digit's shape, so a few key squares can change its totals a lot
  2. The network was never really trained, so it was only guessing
  3. 4 squares is most of the picture, so anyone would be fooled
  4. The network forgets everything it learned when a picture changes

A person sees strokes and shapes. The network only sees 64 numbers and its weights, so changing just the right squares changes its answer.
